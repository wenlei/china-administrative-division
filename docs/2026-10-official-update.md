# 2026年10月官方数据更新

本批于2026-10-20至2026-10-21整理，沿用原有 `patches/<年份>/*.json` 协议。目标分区是2026，基线为2023；保留旧年度及历史补丁。不新增第二套区划库。仓库及 master 均指 `wenlei/china-administrative-division`。

## 民政部接口使用规则

[官方服务说明](https://dmfw.mca.gov.cn/interface.html)的行政区划搜索接口为 `https://dmfw.mca.gov.cn/9095/xzqh/getList`。本批先以省码和 `maxLevel=2` 取得父树，再逐市及省直辖县级市请求，归档每次URL及响应。遇到临时空响应重试；空响应、缺少市县请求、非官方来源和未审查同码异名均拒绝导入。

接口会混入名称为“（撤销）”或“（已撤销）”的历史记录，本批排除这些节点及其子树。不能直接把所有响应当成现势。北泉镇是唯一已审查同码异名例外，规则列出全部原始名称，出现新别名时仍失败。

实测 `year=2026` 和不存在的 `year=2099` 均返回节点，因此本批不据年份参数推断版本。接口也漏列了浙江省厅名录中的若干节点；已取得省厅2026名录的省份继续采用省厅表，不由接口覆盖。

## 数据口径

- 官方六位省市县码、九位乡级码尾补零为原协议十二位码；直辖市保留兼容中间节点。接口直接管理的父树按原文保留；省直辖县级市按原协议使用既有659000中间分组，该分组不是新增行政实体。
- 来源名录之外的旧统计节点仅在2026分区标记deprecated，不物理删除；不据此断言统计单位实体已撤销。历史年度不变。
- NBS统计码与民政码可能同码异名、异码同名；本批校准所选来源的四级视图。
- 村级仍为冻结的2023历史数据。乡级变码后不能把旧村级隶属当作2026现势。
- 江西“（门+合）山镇”、福建“虎氵贝镇”等按来源拆字保留，未臆造字符。
- 所有来源和解析输入均记录SHA-256；动态网页重新下载可能变化，必须重新审查，不可沿用旧哈希。

## 重建本批更新

```bash
pnpm install --frozen-lockfile
pnpm --filter @cndiv/cli build
node packages/cli/dist/cli.js hydrate --year=2023 --cache=/path/baseline
node scripts/materialize-official-update.mjs \
  --baseline=/path/baseline/cache.db \
  --sources=updates/2026-10.sources.json \
  --output=/path/new-october-output
```

输出目录必须不存在。脚本保留输入库除目标2026以外的所有历史分区，按清单顺序重放2024、2025事件、已有2026合并补丁、31省官方补丁及湖南10月公告。不能用通配符无序重放，不能只应用旧2026.merged.json。

仅在补丁协议、四级有效父链、31省乡级数量、逐字段历史保留、补丁审计数及SQLite完整性全部通过后，发布cache.db、coverage.json及replay.log。`--require-complete` 因20省旧版/无日期来源而拒绝构建，不把覆盖31省等同于全国现势认证。

原CLI导出仍包含村级和deprecated节点；使用四级视图须筛选 `year=2026 AND level<=4 AND status='active'`，并读取coverage.json。

## 从归档原件生成补丁

原件沿用项目raw目录本地归档约定，不提交大文件和数据库。按清单保存原件及解析输入；安装beautifulsoup4、xlrd、openpyxl、pdfplumber。PDF文字表用pdftotext -layout；河北、浙江使用固定版面提取脚本；青海DOC先用textutil -convert txt转换为63-attachment-0.txt。

```bash
python3 scripts/extract-official-gap-tables.py --raw /path/archived-originals
python3 scripts/build-official-update.py \
  --sources updates/2026-10.sources.json --raw /path/archived-originals \
  --baseline /path/baseline/cache.db --output patches/2026
python3 -m unittest discover -s scripts -p "test_official_update.py"
node scripts/validate-patches.mjs
python3 scripts/verify-official-update.py \
  --sources updates/2026-10.sources.json --raw /path/archived-originals \
  --database /path/new-october-output/cache.db
```

6省接口原件为每省*-mca-snapshot.json，包含retrieved_at、declared_as_of=null及requests数组，每项保留官方URL和原始response。重新采集须重新审查哈希及别名冲突，不把新响应冒充本批归档。湖南6条公告单独维护。
